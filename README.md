# АС «Аптека»

Курсовая работа по дисциплине «Проектирование и архитектура программных систем».

Веб-приложение на **ASP.NET Core MVC** + **PostgreSQL** для учёта препаратов, категорий, поставщиков, поступлений и продаж.

## Запуск

1. Установите .NET 9 SDK и PostgreSQL.
2. Создайте БД `pharmacy`.
3. Укажите строку подключения в `Pharmacy/appsettings.json` (пароль вместо `YOUR_PASSWORD`).
4. Запуск:

```bash
cd Pharmacy
dotnet run --launch-profile http
```

Откройте http://localhost:5080

## Структура

- `Pharmacy/` — исходный код MVC-приложения
- `docs/` — пояснительная записка (Word) и генератор отчёта
